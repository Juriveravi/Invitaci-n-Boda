# Invitación de boda
1. `npm install`
2. `npm run dev` (prueba local) / `npm run build` (genera /dist)
Edita nombres, frase, fecha y enlace en `src/config.js`. La foto está en `public/pareja.png`.
## Audio local opcional

El reproductor se activa cuando `src/config.js` incluye una ruta de audio local en
`cancionUrl`. Los archivos de audio están ignorados por Git para no publicar
material protegido sin autorización.
